# BAEUGO 모바일 웹 시연본

이 프로젝트는 수강자와 강사 시나리오를 모바일 화면에서 직접 확인할 수 있는 시연용 웹입니다.

## 실행

프로젝트 폴더에서 아래 명령을 순서대로 실행한 뒤 `http://localhost:3000`을 엽니다.

```git bash
npm install
npm run dev
```

휴대전화 화면으로 보려면 브라우저 개발자 도구의 모바일 화면 모드를 사용하세요. 실제 휴대전화에서는 컴퓨터와 같은 Wi-Fi에 연결한 뒤, 필요하면 `npm run dev -- --hostname 0.0.0.0`으로 실행하고 `http://컴퓨터의IPv4주소:3000`에 접속합니다. 화면은 최대 430px 너비로 설계했습니다.

## 확인할 흐름

- 수강자: 온보딩(상황, 직무, 주제) → 홈의 수강 강좌와 세로 풀화면 OT → 탐색·검색 → 강좌 상세 → 체험용 구매 → 강좌의 영상과 단위 확인 퀴즈를 세로 스와이프로 순서대로 학습 → 코스 종합 퀴즈(강사 직접 출제 및 1회 재출제) → 보관함의 수료 강좌, 오답노트, 메모
- 강사: 온보딩 → 강사 대시보드 → 강좌 등록(무료 OT 필수, 코스 퀴즈) → 강좌 관리(강좌 정보 → 영상 관리 → 퀴즈·대본 검수 → 저장) → 강사 통계 → 강사 마이페이지

## 시연 범위

구매는 실제 결제 없이 수강 권한만 열립니다. 강사가 선택한 영상은 이 브라우저의 IndexedDB에 저장됩니다. 브라우저 저장 데이터를 지우거나 다른 기기에서 열면 업로드한 영상은 공유되지 않습니다. STT 대본과 AI 퀴즈는 편집 가능한 예시이며 외부 서비스와 연결되지 않았습니다. 수강자 통계도 이 브라우저의 체험 계정 기준입니다. 실제 출시에는 서버 저장, 결제, STT·AI, 다중 사용자 집계가 필요합니다.

강사 Q&A, 학습 알림, 배속 조절, 리워드는 1주차 기획서의 후속 고도화 항목으로 이번 시연본에 포함하지 않았습니다.
